# Giro 2

Sitio estático independiente para presentar un concepto de Giro d’Italia Ride Like a Pro México.

- Identidad: logotipos del proyecto Giro México y color oficial del *STYLE GUIDE - ride like a pro* (`#ff286e`, RGB 255/40/110). Logotipos sin alteraciones; Poppins local con licencia OFL.
- Voz: *Voz de Marca Ride Like a Pro México — edición revisada* y *Manual de Voz Giro Italia México 2027*: inspiradora, cercana y precisa; herencia Giro + reto personal + ciclismo mexicano.
- La imagen del pelotón es ilustrativa, no documentación del evento.
- Ciudad y fecha provienen de la página de referencia y requieren confirmación oficial. Sin URL de registro verificable no se muestra un botón de pago o inscripción.

Desarrollo local: `python3 -m http.server 8080`.
