# Giro 2

Sitio estático independiente, inspirado en la página de referencia del Giro México y adaptado al *Manual de Voz Giro Italia México 2027* del workspace.

- Voz: inspiradora, cercana, precisa, apasionada y auténtica.
- Territorio editorial: «El Giro se rueda en México»; herencia italiana + historias locales.
- Sin formulario ni pagos: la referencia no tiene enlace real de registro (usa `#`), y las condiciones del evento no están verificadas.
- La fecha y ciudad se muestran como datos de la página de referencia, no como confirmación oficial.

Para desarrollo local: `python3 -m http.server 8080` desde esta carpeta.
